# 可能是集换卡牌

在《Probably Stolen》的店里多做一门生意。你可以看封口、和散货商谈价，把原封卡包转手卖掉，也可以拆开碰碰运气，把喜欢的卡收进册子。

## 安装与第一次进货

已在 Steam 正式分支的 100-Rev13 验证。

1. 在 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3842861920)订阅，或从 [GitHub Releases](https://github.com/XJfyrh/ProbablyTradingCards/releases) 下载 `ProbablyTradingCards-v<版本>.zip`，解压后把 `ProbablyTradingCards` 文件夹放进游戏安装目录的 `Mods`。使用工坊版时，请将同 ID 的手动安装副本移出 `Mods`。
2. 启动游戏，在模组列表启用“可能是集换卡牌”，按提示完成审核并重启。
3. 进店开门。第一次接待供货客时，周二来的是发行商业务员，其他日子来的是码头散货商。将鼠标悬停在卡包上看封口描述，再到柜台买下看中的货。

每周二，发行商带来限量原厂货。每周四，码头散货商固定带三包卡、一张 C 和一张 R 单卡。错过散货商时，下次开门还能接这批货。散货商允许议价，他的卡包有 25% 的概率经过二次封装，买包前记得看封口。

第 12 天起，黄牛每周五带《空间站传奇》的原封散包和一张完好的基础卡。每周可以买一包、一张单卡。瘦包 270 信用点，肥包上架后卖 1,080。单卡按完好基价的三倍一口价出售。整盒发售后，他偶尔还会多带一盒。

如果已安装的扩展辑到了发售日，发行商每次到访只让你选一批货。想买某一辑的卡包和收藏簿，就选该辑。想买夜话或传奇，就选常规商品。下次到访时可以重新选择。

关店后去垃圾场，拾荒成功时偶尔能从战利品里翻到一张单卡。把它捡进口袋或背包才能带回店。捡来的卡大多有折痕，偶尔也能翻到一张稀有卡。垃圾场只会出已经发售的夜话和传奇基础卡。

## 手撕、用刀，还是原封卖掉？

买下卡包并放进物品栏后，双击或右键选择“激活”即可手撕。每张卡有 25% 的机会降一级品相，最低降到“有折痕”。想保住原品相，可以用自己的美工刀点击卡包，刀可重复使用。开启单击激活后，单击即可拆包。拖动包装可以换位置。

整盒也能双击拆封或用刀切开，一次取出其中的全部原封包。单卡和内包优先放入玩家库存，再尝试后柜台。两处合起来仍放不下时会保留原包装。腾出位置后再开，里面还是同一批货。

原封出售时，各规格都有自己的基价。拆成单卡后，有折痕、轻微磨损和完好的卡分别按完好基价的 30%、75% 和 100% 计价，再计算原版行情与议价修正。

| 第 16 天 | 《空间站传奇》肥包 | 9 张卡 | 576 | 2 |

《空间站夜话》有九张卡，分 C、R、SR 三档。每包前两张都是 C，正版包的第三张有 34% 的机会出 R、6% 的机会出 SR。二封包对应的概率是 9% 和 1%。

《空间站传奇》有四十张常规卡，最高为 UR。正版瘦包第三个常规卡位至少是 R，正版肥包第九个常规卡位至少是 SR。原封整盒的基础配货至少含一张 SSR 或 UR。散货商从第 9 天起也可能带瘦包，第 16 天起可能带肥包。

## 收藏和找买家

双击单卡或右键选“阅读”可以查看卡面。买下之前也能查看，留意卡边的磨白、划痕与折线。打开相应系列的集换册，把卡拖进同名卡位。每个位置收一张，随时可以取出出售。

《空间站夜话》的九张卡共用一本集换册。《空间站传奇》使用第 9 天开始供货的星港收藏簿，用页脚按钮翻页。剧情和活动还会开放十一张隐藏异画，发现后对应的卡位才会出现。有的异画可以在查看窗口里切换画面，持有的卡会保存你的选择。

拆传奇卡包时，当前运气会影响异画出率。可以把正版包留到异画开放，再挑运气好的时候拆。

买下店铺、集齐《空间站传奇》的 40 张基础卡，再持有自己故事结局的异画，下次开门时会有一位卡商带来其他结局中还缺的卡。散卡和收藏簿里的卡都算数。货是完好的，一口价，错过了下周还会来。

| 想卖什么 | 找谁 |
| --- | --- |
| C、R、SR 单卡 | 周五找夜班收藏客。C 级普通单卡也可以卖给收日用品的顾客。 |
| 未拆散包 | 持有散包时，拆包爱好者会在周六来访，第一辑也收。他按封口报价，能买多少看当天的预算。 |
| SSR、UR 单卡 | 打开自己的卡面，悬停「预约收购」查看报价和日期。点击后，下次开门可按这笔报价成交。每次挂一张，也可以取消。 |
| 传奇原封盒 | 原封收藏客瘦盒、肥盒都收，每次买一盒。 |

第 23 天起，发行商也会转告本周的专题求购。专题收藏客周日来收对应的普通 R／SR，人物、道具主题交替，每次最多三种。

开门前，可以把原封包装、单卡或装有卡的集换册摆进展示柜。店铺吸引力达到 100 后，可在客流预测中查看对应收购客的来访机会和剩余冷却。开门时，同一卡种只按品相最好的一张计算邀请。

## 保存与卸载

照常保存游戏即可保留卡包内容、单卡品相与册内收藏。继续游玩含有这些物品的存档时，请保持模组启用。准备卸载时，先处理库存、柜台和册子里的模组物品，保存后再移除模组。
