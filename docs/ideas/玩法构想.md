# 待讨论的玩法

在《收藏悬赏》示例中，编辑收齐三张人物卡，另付 120 信用点。下面的构想包括按卡名和品相交货，以及随行情变化决定何时出售。[《收藏悬赏》玩法](../../Examples/CollectionBounty/README.md)

| 想法 | 玩家可以做什么 | 仍要决定什么 |
| --- | --- | --- |
| 精密称重与放大镜验包 | 收购前再查一条封口以外的线索 | 包材、填充物与稀有卡的重量有多少重叠？放大镜能看到哪种痕迹？ |
| 卡套、封装与评级 | 保护贵卡，拿到买家认可的品相评级 | 封装消耗什么？拆封后怎样识别原卡并核实评级来源？ |
| 预组包、散卡盒和福袋 | 把占格的散卡组成一件商品出售 | 谁决定售价和组合？成交前买家能看到哪些卡？ |
| 指定收藏需求 | 按联系人点名的卡片与品相交货 | 怎么认识这位买家？哪些收藏要求需要提前告知玩家？ |
| 动态行情 | 根据将来的需求决定囤货还是回款 | 行情变化多快，玩家从哪里得知，压货多久仍有现金进货？ |
| 日历提示异画期限 | 完成相关剧情后，在游戏日历查看限时异画的最后一天 | 哪些结束日适合显示？重复发生的活动怎样沿用原版新闻提示？ |
