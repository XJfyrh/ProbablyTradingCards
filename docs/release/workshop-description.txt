空间站怎么能缺少集换卡牌呢？于是我花了几天时间，快速产出了这个 slop……AA 模组！
（注：AI 美术、AI 制作。）

[h2]以下是模组的简要介绍[/h2]
现在有《空间站夜话》和《空间站传奇》两辑，49 张常规卡，还有……

[list]
[*]找发行商进原厂货，会更贵！跟散货商买之前记得看看封口，可能是二封货。
[*]手撕卡包可能会伤卡。
[*]舍不得卖的就收进集换册吧。
[/list]

订阅后，在游戏的「模组」菜单启用「可能是集换卡牌」，按提示审核并重启。目前是简体中文。
